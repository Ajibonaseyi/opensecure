Gateway OpenAPI Contract & Routing Architecture

v1.4 Protected

External TPP connections authenticate via mTLS at https://gateway.opensecure.local. Access tokens are validated locally against Keycloak's published JWKS keys (signature, issuer, audience, expiry) alongside granular consent scope checks, then proxied to the core banking upstream over plain HTTP inside an isolated private network.
